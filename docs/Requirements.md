About the feature
The result should be a styled login page that leads into a team page. The team page will have information about the project team.

User story 
As a user, I want to access a styled login page and view a team page so that I can learn about the project and the team members.

Requirements
x2 pages
Login Page
1.	The login page must provide a styled login page using the current boilerplate
2.	The login page must maintain the existing boilerplate's authentication functionality.
3.	The login page should clearly proceed to the team page
Team Page
1.	The team page must display the team name.
2.	The team page must display the project name.

3.	The team page must display each team member's photo.
4.	The team page must display each team member's name.
5.	The team page must display each team member's role.
6.	The team page must display a short about-us blurb for each team member.
7.	Team member information must be presented consistently for all members.

Display Requirements
•	The team’s name and project name must be clearly visible.
•	Team member information should have a consistent layout.
•	The feature should work within the existing boilerplate structure.

Edge Cases
The following should be taken into consideration:
•	A team member’s name is longer than other members.
•	A team member's about-us blurb is longer than other members' blurbs.
•	A team member photo is unavailable or cannot be loaded.

Login Scope
In Scope
•	Styling the existing login page
•	Team name display
•	Project name display
•	Team member photo display
•	Team member name display
•	Team member role display
•	Team member about-us blurb
•	Consistent styling and presentation
•	Using the existing boilerplate
Out of Scope
•	Changing the authentication logic
•	New authentication functionality
•	User registration
•	Password reset
•	User profile management
•	Admin functionality

Acceptance Criteria for the Feature
•	Styled login page is implemented using the existing boilerplate.
•	Existing authentication behaviour remains unchanged.
•	Team name is displayed.
•	Project name is displayed.
•	Each team member has a photo displayed.
•	Each team member has their name displayed.
•	Each team member has their role displayed.
•	Each team member has an about-us blurb displayed.
•	Team information is presented consistently.
•	Login and team pages have consistent styling.

Handoff comment
-	The requirements make sure all team members’ have the necessary information presented on respective page
-	If team member information isn’t available – the page should still be able to function and remain consistently displayed. 
-	The UX role should use these requirements to create the page designs
-	Development should use these requirements and the approved design when implementing the feature.
